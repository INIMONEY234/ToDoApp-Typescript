# ToDoApp-Typescript

# TypeScript Todo App

A simple Todo List application built with TypeScript.  
This project demonstrates the use of:

- Interfaces
- Classes
- Arrays
- Methods
- Error handling
- Optional properties
- Filtering and updating data in TypeScript

---

## Features

The application can:

- Add new todo tasks
- Mark tasks as completed
- Remove tasks
- Display all tasks
- Filter completed or active tasks
- Update task descriptions
- Clear completed tasks
- Assign optional due dates

---

## Technologies Used

- TypeScript
- Node.js

## Error Handling

The application handles errors such as:

- Empty task entries
- Updating non-existing tasks
- Completing non-existing tasks

Example:

```ts
throw new Error("Task cannot be empty");
```
